# Python para análisis estadístico

Este repositorio contiene notebooks de Python para una sesión introductoria de análisis estadístico aplicado a biología.

## Contenido

### `Clase/`

- `analisis_estadistico_python.ipynb`: notebook de clase con actividades para completar.
- `analisis_estadistico_python_completo.ipynb`: versión resuelta del notebook de clase.

### `Cheatsheet/`

- `numpy_cheatsheet.ipynb`: referencia rápida de NumPy.
- `scipy_cheatsheet.ipynb`: referencia rápida de SciPy.

## Ejecución

Los archivos `.ipynb` se pueden descargar y ejecutar en [Google Colab](https://colab.research.google.com/) sin necesidad de instalar Python en el computador.
